В данном документе описаны проверки, спроектированные до начала разработки автотестов.

| № | Название | Шаги | Ожидаемый результат |
|:---|:---|:---|:---|
| **ТК-01** | Создание объявления с обязательными параметрами | 1. Отправить POST на `/api/1/item`. <br> 2. Указать: `sellerID` (int), `name` (string), `price` (int). | Код **200**. Товар создан. |
| **ТК-02** | Получение данных объявления по ID | 1. Отправить GET на `/api/1/item/{id}` (использовать ID из ТК-01). | Код **200**. Тело содержит `id`, `name`, `sellerID`. |
| **ТК-03** | Получение всех объявлений продавца | 1. Отправить GET на `/api/1/{sellerID}/item`. | Код **200**. Массив всех объявлений продавца. |
| **ТК-04** | Получение статистики объявлений | 1. Отправить GET на `/api/1/statistic/{id}`. | Код **200**. Есть поля `likes`, `viewCount`, `contacts`. |
| **ТК-05** | Получение несуществующего объявления | 1. Сгенерировать случайный ID. <br> 2. Отправить GET на `/api/1/item/{random_id}`. | Код **404 (Not Found)**. |
| **ТК-06** | Создание товара с некорректной ценой | 1. Отправить POST на `/api/1/item`. <br> 2. В поле `price` передать строку (например: "бесплатно"). | Код **400 (Bad Request)**. Запись не создана. |
