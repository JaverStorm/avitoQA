В данном документе находятся баги, выявленные в результате тестирования.

| № | Заголовок | Приоритет | Шаги воспроизведения | Фактический результат | Ожидаемый результат |
|:---|:---|:---|:---|:---|:---|
| **БГ-01** | **Метод GET /api/1/item/{id} возвращает массив вместо объекта** | Medium | 1. Создать объявление и получить его `id`. <br> 2. Отправить GET запрос на `/api/1/item/{id}`. | Сервер возвращает массив объектов. | Сервер должен возвращать один объект. |
| **БГ-02** | **Ошибка 400 Bad Request при отсутствии объекта statistics в методе POST /api/1/item** | High | 1. Отправить POST запрос на `/api/1/item`. <br> 2. В теле запроса указать только базовые поля: `name`, `price`, `sellerID`. <br> 3. Отправить запрос. | Сервер возвращает 400 Bad Request с сообщением "поле likes обязательно". | Объявление успешно создано (200), поля статистики инициализированы значениями по умолчанию (0) сервером. |

**Комментарий к БГ-02:**
Так как при создании товара требуется задать `statistics` – становятся возможными манипуляции с лайками. На этапе создания товара уже можно накрутить нужное кол-во лайков.
